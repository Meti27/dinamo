# Dinamo Orašje

One static page for a burger-and-ice-cream shop in Orašje, Bosnia and
Herzegovina. Its centrepiece is a scroll-linked image sequence: the burger comes
apart into its ingredients, holds while they are labelled, and goes back
together — scrubbed frame by frame against the scroll position.

## Running it

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # type-checks, then emits a static dist/
npm run preview    # serve the built dist/
npm run frames     # rebuild the sequence from assets/source/burger-frames.zip
```

`dist/` is plain static files — host it anywhere. There is no server, no
database and no router.

## How the sequence works

The source is 30 PNGs of the burger over a studio backdrop. It only runs
**closed → apart**, so the way back is the same frames in reverse — which is
where "the burger goes back together" comes from without a second sequence.

`scripts/build-frames.py` cuts the burger out. The backdrop is baked into the
PNGs but never moves, so it can be modelled and subtracted: a cubic surface is
fitted per channel to the pixels outside the box the burger and its shadow never
leave, then used to predict the backdrop *behind* the burger, which a median
across frames can never recover because the burger never clears the middle of
the frame. The fit reproduces known background at 1.7/255 and extrapolates just
as accurately. The result is cropped to the burger — 19% of the source area —
and encoded to AVIF with a WebP fallback.

The script also measures where each labelled ingredient sits, per frame. These
layers never fully separate, so it finds the **waists** in the burger's outline
rather than gaps between it: the row-width profile dips sharply between one
ingredient and the next, and the deepest dips are the seams.

`BurgerStory.tsx` pins the stage with ScrollTrigger and scrubs it. Progress maps
to a frame position with a **hold** in the middle, because a pose that never
stops moving cannot be read and the point of the beat is to look at the
ingredients. Neighbouring frames are cross-dissolved, which is what turns 30
stills into continuous motion — and it has to be a linear dissolve (`lighter`),
because these frames carry alpha and painting one over the other leaves two
burgers.

Every frame is preloaded and decoded before the scrub is allowed to start, so
nothing is ever seen half-loaded. `prefers-reduced-motion` skips all of it and
renders two stills.

## Rules worth keeping

- **Nothing in the scroll-driven path may read or write layout.** Geometry is
  measured once per resize into a plain object; the loop writes only `opacity`
  and `transform`, plus the canvas blit. Measured: 28 layouts across a 91-step
  scrub, 0.42 ms of script per frame.
- Don't position an element with a CSS `transform` that GSAP also tweens — the
  tween overwrites it. Centre with flex instead.
- **Never let two tweens own the same property.** A one-shot entrance and a
  scroll-driven exit on the same `opacity` means reversing the scrub restores the
  entrance's recorded values, and the element never comes back. One timeline,
  `fromTo` everywhere, and put entrances on a child element.
- **No `animation-timeline: view()` on content that must be visible.** With
  `animation-fill-mode: both` it pins the element at opacity 0 until the browser
  decides it entered — and jumping to a section via an anchor never advances it,
  so the whole menu renders blank.
- A non-square image under `border-radius: 50%` is an ellipse. The crest is cut
  to a transparent square by `scripts/build-logo.py`.
- Anything GSAP fades in must start hidden in CSS, or it flashes at full
  strength before GSAP runs.
- `ffmpeg`'s AVIF muxer drops the alpha plane; frames go through `avifenc`.
- After rebuilding frames, restart the dev server — Vite serves empty bodies for
  files whose directory was deleted and recreated underneath it.

## Content

Business facts, both translation tables and the menu live in `src/data/`. The
five ingredient labels are matched to what the footage actually shows: this
burger has no pickle or sauce layer and its cheddar never separates from the
patty, so labels for those would point at nothing.
